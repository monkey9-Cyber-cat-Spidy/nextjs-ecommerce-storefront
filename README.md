# Next.js E-Commerce Storefront

Full-featured modern e-commerce storefront engineered with **Next.js 15 App Router**, **React Server Components (RSC)**, **PostgreSQL relational database schema**, and **Supabase Database Webhooks**.

## Highlights
- **Sub-Second TTFB**: Instant product rendering via Server-Side Rendering (SSR).
- **Relational Cart & Checkout**: Normalized schema for products, variants, orders, items, and customer transactions.
- **Supabase Webhooks**: Event-driven background tasks dispatching invoice generation.
